## Problem Statement
In order to sign up and login succesfully, the user needs to enter data that is secure and in allignment to the necessary datatype and format . E.g. hwr-email requires a specific ending and the Matrikelnr needs to contain a total of 11 INT Numbers with the beginning of 7720...  



## Decision
1. Using and utilizing WTForms in order to set requirements for the users input, sign up aswell as login data (forcing the user to create a secure password with the help of Regexp etc.) all that while maintaining compact and readable syntax (Danial Banitorfi) (-->loginbp.py class RegisterForm)


## Regarded Options

It would've also been possible to set the criteria for each input data manually, which bring about the con that its syntactically taxing, epecially when multiple input data fields are at display. The advantage of that would be that one were to use a bit more HTML syntax instead of Jinja which can be a bit simple to work with, as far as simple actions are concerned.
