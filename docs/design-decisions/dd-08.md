# 08: db_reinigen module to delete unnessesary copy of same anfrage / abgabe in DB

## Meta

Status
* **Status**: Decided
* **Updated**: 23-Jun-2026

## Problem Statement

While working on theglobal_tauschfindung method there occured a problem with the same abgabe anfrage data in db of same user and it messed up the fifo principe so that the same abgabe got patnered with multiple anfrage because abgabe had mutliple entry in database or other way around.

## Decision

i decided to add a function to clean up the database from redundand data from same user for same abgabe / anfrage so that only the first entry (sorted by time/ oldest entry of same kind) was left the other ones was deleted to clean up the database and make the global_tauschfindung to work properly. this function gets triggered each time when the global_tauschfindung method gets run so it cleans up the database regularly before finding exchaneg-patners and putting them into the tausch table in the db.


## Regarded Options

we could have just left it that way and implemented a security-feature that checks if already a redundand entry of a abgabe / anfrage is in the db while the student tries to add anotherone, and the student gets warned the already has an entry and no new ones get made.

but this way it is easier to maintain and comprehend how this funcitons.
