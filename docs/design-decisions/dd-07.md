# 07: RETURNING PROFILE INFORMATION AS JSON ON /PROFILE_API

## Meta

Status
* **Status**: Decided
* **Updated**: 23-Jun-2026

## Problem Statement

We was unsure where and why to put the mandotory JSON API 

## Decision

I asked the other Teammates what they thought about this problem.
They where unsure too.
So i said lets make the json api return the logged in profile information
They agreed.

## Regarded Options

We could have made the json api return the module,course,tausch lists as json but the problem with that would be it would be unnecessary,
because it should only be viewed by the studienburo accounts.

It is a good idea to return the account data as json in a seperate view "/profile_api" as it works with evry user of our webapp (students and studienburo members);

Also it could be used to link in other applications later on as the json returns important user data;
